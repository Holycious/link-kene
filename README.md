# kene. — link-in-bio

**kene.studio** menghadirkan homedress premium — busana rumah yang nyaman dipakai seharian tanpa mengorbankan tampilan rapi, dengan bahan dan jahitan yang dipilih untuk pemakaian jangka panjang.

Halaman ini adalah satu tautan resmi kene.studio di bio Instagram/TikTok, menghubungkan pengunjung langsung ke tempat belanja dan ke admin untuk pertanyaan seputar stok, ukuran, atau pemesanan custom:

- **Belanja di Shopee** — katalog lengkap & checkout cepat
- **Belanja di TikTok Shop** — promo & live sale
- **Chat Admin** — tanya stok, ukuran, & pemesanan custom
